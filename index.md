# 🚀 port-forward - Simple Linux Port Forwarding Management

## 🛠 Overview
Port-forward is a Linux application that helps you manage port forwarding easily. It supports seven different methods: iptables, HAProxy, socat, gost, realm, rinetd, and nginx. With a one-click deploy feature and automatic kernel optimization, using port-forward will save you time and effort. The application also enables BBR for better performance and features an interactive command-line interface (CLI) for easier access.
